## 🔬 What I'm working on

| | Repository | In one line |
|:---:|:---|:---|
| 🦿 | **[Cross-Embodiment Humanoid Skill Transfer](https://github.com/Santiago23florido/lHumanoid-Soccer-Isaac-Lab)** | A locomotion skill learned on a Unitree G1 runs zero-shot on a NAO nine times lighter — 192/192 episodes without a fall, in Isaac Lab. |
| 🖐️ | **[Musculoskeletal Hand Control from Motor Units](https://github.com/Santiago23florido/Musculoskeletal-Hand-Simulation)** | Decoding individual motor units from HD-sEMG while the limb moves fast, to drive a simulated hand — 87.4% vs 76.9% on a held-out subject. |
| 🩺 | **[Safe Autonomous Catheter Navigation](https://github.com/Santiago23florido/safe-autonomous-catheter-navigation)** | An 81-body flexible catheter in Isaac Lab, with wall-contact force as a constraint rather than a reward term. |
| 📈 | **[CAGE-NAS](https://github.com/Santiago23florido/functional-gradient-growth)** | Certifying when a network should grow instead of training further — NeurIPS 2026 workshop. |

> Each repository states the limits of its own evidence: what is simulation, what data is
> synthetic, and what has not been built yet.
